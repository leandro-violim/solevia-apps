# Audio on hold — not shipped

## arena-of-glory.m4a  ("Arena of Glory")

**Status: held out of the shipping build pending a licence answer.**

Source: ElevenLabs **Music Marketplace** (Sole Via account, Starter plan).

Why it is held: the Music Marketplace Addendum (elevenlabs.io/mma) scopes the
grant to the **usage type purchased** — Social Media, Paid Marketing, Offline,
or Enterprise. None of those names games or apps. Separately, Eleven Music
excludes "Studio Games", defined as *video games which are commercialised
(either by sale, advertising or any other forms of monetisation) and made
available for download or use through more than one platform*. Cap Kickers is
monetised (ads + IAP) and ships on both the App Store and Google Play, so it
falls squarely inside that exclusion.

This is **not** a claim that the track is unusable — only that no self-serve
Marketplace usage type visibly covers this use. Two ways it comes back:

1. Written confirmation from ElevenLabs (support or legal) that the purchased
   usage type covers a monetised multi-platform game. Save the reply next to
   this file as `arena-of-glory-CLEARANCE.md` before re-bundling.
2. Purchase of an Enterprise / bespoke usage type that names games.

Until one of those exists, this file stays here and is **not** imported by
`src/lib/menu-music.ts`.

Kept because the track itself is a good fit and worth reinstating if cleared.
