## 1 · Coins & currency (foundation)
Earn: Time Attack end `coins = round(score/25)` + objective rewards. Zen ~1 coin / 15 bubbles.
Daily/streak, rewarded double-coins, achievements. Spend: skins/themes shop.
`{ coins }` in storage; `addCoins(n, source)` / `spendCoins(n, sink)` fire analytics resource
events. UI: balance on home + shop; "+N coins" count-up on score screen. No negative balance.

## 2 · P1-T3 · Interstitial cap & relocate (📱)
Only at natural breaks (after run / score screen / clean phase stop). Never app-open, run-start,
mid-play. Cap ≤1 per 3 completed runs AND ~75s cooldown. No interstitial on first run of session.
Tunable. Closeable. Test interstitial IDs.

## 3 · P1-T4 · Rewarded ads (📱)
Opt-in, labeled, closeable: (1) Revive/+15s when TA timer hits 0 (resume same run, score/combo
intact, max 1/run tunable to 2); (2) Double coins on score screen; (3) Shop: watch to unlock a
skin for the day OR discount its price. Skip/close/no-fill/load-fail → proceed, never soft-lock.
Google TEST rewarded IDs now; real slots marked `TODO(admob): real rewarded units (iOS+Android)`.

## 4 · P1-T5 · Daily bonus (built — rework reward)
Existing once-a-day pop-up + `{lastBonusDate, consecutiveDays}`. Now grants coins scaled by streak
day (§5 table), existing gold flourish. Calm/gift-like.

## 5 · Streaks
Escalating coin table (tunable): D1 20 · D2 30 · D3 45 · D4 65 · D5 90 · D6 120 · D7 175, then
repeats with D7 as weekly milestone. Streak-freeze: missing a single day doesn't reset the first
time (auto-freeze once, refreshes weekly); a miss with no freeze resets to Day 1. Show streak on
home + daily card ("Day 5 · 🔥").

## 6 · Skins/themes + shop
~6 bubble skins (Classic, Neon, Pastel, Ocean, Night, Gold) + ~4 backgrounds (Soft Light, Sunset,
Deep Sea, Starfield). Art supplied by Cowork — define asset slots/naming. Shop grid: price,
owned/equip, preview. Buy with coins; equip toggles active. One premium gated behind streak
milestone or rewarded unlock. Prices (tunable): common 150 · uncommon 350 · rare 600 · premium 900.
Persist owned + equipped.

## 7 · Special bubble types
Tunable spawn rates, phase-introduced: Golden ~3% (bonus pts+coins) · Bomb ~2% (pops neighbors) ·
Mystery ~2% (random reward) · Chain (short sequences) · Frozen ~3% harder phases (2 taps). Distinct
look + pop cue. Zen: rare/off. No perf regression.

## 8 · Objective cards (Time Attack)
1–3 optional per run (e.g. "Pop 50 without a miss", "Hit ×15 combo", "Clear phase 3 with 5s left",
"Pop 5 golden"). 15–40 coins each. From a pool, vary each run. Small non-nagging UI.

## 9 · Modes + phases/difficulty (integrating layer)
Home offers TWO modes. Zen: no timer, endless generative bubbles, calmer juice, gentle coins,
bubbles-popped stats, specials rare/off, combo feedback-only, optional soft goals. Time Attack:
race-the-clock, scoring incl best-combo×15 (RESOLVED: TA combo→score, Zen feedback-only), objectives,
specials, rewarded revive, difficulty, phases+endless, daily challenge. Phases 5→8 (author 6–8) +
Endless. Difficulty Easy/Normal/Hard (time, size, spawn speed); Endless also drives Zen spawn feel.

## 10 · Achievements
~10 one-time w/ coin rewards: Pop 1,000 · Pop 10,000 · 7-day streak · 30-day streak · ×25 combo ·
No-miss run · Clear all phases · Pop 100 golden · Own 3 skins · First revive. Achievements/stats
screen; unlock toast + coin grant.

## 11 · Analytics SDK
Recommended GameAnalytics (or Firebase). Owner creates account/app for keys (iOS+Android); no-op
until wired. Events: session start; run start/end (mode, score, phase, bubbles, max combo);
rewarded offered/watched/skipped (placement); interstitial shown; daily bonus shown/claimed (day);
streak day; coins earned/spent (source/sink); skin unlocked/equipped; achievement unlocked;
objective completed; mode selected; daily challenge played (score). No PII; keys configurable.

## 12 · Local daily challenge
Date-seeded Time Attack run (seed from local date → same layout/params for everyone that day). One
highlighted attempt/day; store local best for today + small history. No online leaderboard yet.
Bonus coins for playing. Home entry with today's status. Changes at local midnight.
